# 🎲 SkewbPage Companion — Layer-to-Layer Case Atlas

### *A field guide for solvers who believe every scramble is just a story waiting to be finished*

Welcome to the **SkewbPage Companion**, a structured, human-readable knowledge base dedicated to the beautiful, twisty world of Skewb layer-to-layer (L2L) solving. Where the original SkewbPage project offered hints and solutions for every L2L scenario, this repository takes that same spirit and expands it into a full-fledged atlas: a living, breathing reference that treats each case like a constellation — small on its own, but part of a larger sky once you learn to read it.

Think of this repository as a **pocket observatory for twisty-puzzle thinkers**. Every case is catalogued, cross-referenced, and explained in plain language so that newcomers and seasoned cubers alike can navigate the layer-to-layer method with confidence.

---

## 🌟 Why This Repository Exists

There is a peculiar moment in every Skewb solver's journey when the puzzle stops being a jumble of corners and starts becoming a *language*. That moment rarely arrives through brute repetition alone — it arrives through understanding. This Companion was built on that belief.

Instead of dumping a list of algorithms and calling it a day, the **SkewbPage Companion** organizes each L2L case into a coherent narrative: what the case looks like, why it appears, which rotations simplify it, and which solution path feels most natural. The goal is not memorization for its own sake, but recognition — the kind that makes a solver pause, smile, and say *"ah, I know this one."*

## 🧠 The Philosophy Behind the Atlas

Solving a Skewb is not unlike reading a poem in a language you've only half-learned. The first pass is awkward, the second is smoother, and by the tenth you begin to notice rhythm — patterns that were invisible before. The SkewbPage Companion is designed to accelerate that arc.

We treat every case not as a problem to be crushed, but as a character in a story. Some characters are shy and only appear when you're not looking. Others are loud and demand attention immediately. Learning to recognize them, greet them, and send them on their way is the art of L2L solving.

---

## 🌀 What Is Layer-to-Layer Solving?

Layer-to-layer (L2L) is one of the foundational approaches to solving the Skewb. Rather than trying to solve the entire puzzle in one sweeping motion, L2L breaks the puzzle into two comprehensible layers, then handles the interaction between them with a small library of targeted maneuvers.

It's a bit like assembling a sandwich: you prepare the bottom layer cleanly, you prepare the top layer cleanly, and then you figure out how the two layers want to sit together. The "interaction" cases — where the two layers disagree — are the heart of this atlas.

## 🗂️ Repository Structure

The repository is organized into a logical, browsable layout:

- **`/cases/`** — One folder per L2L case, containing diagrams, descriptions, and solution notes.
- **`/learning-paths/`** — Curated sequences for different skill levels.
- **`/glossary/`** — Definitions of Skewb terminology and notation conventions.
- **`/translations/`** — Language packs for case descriptions and UI strings.
- **`/community/`** — Contribution guides, code of conduct, and volunteer instructions.
- **`/docs/`** — Long-form articles about method variations and recognition tips.
- **`/scripts/`** — Utility routines for generating diagrams, validating case data, and building the companion site.
- **`/assets/`** — Shared fonts, iconography, and stylesheet foundations.

## 🧩 Case Categories at a Glance

Cases are grouped into intuitive families so solvers can build recognition momentum:

- **🌱 Beginner Families** — Simple three-move-style cases and near-trivial patterns.
- **🌿 Intermediate Families** — Cases requiring recognition of corner orientation pairs.
- **🌳 Advanced Families** — Multi-step cases with subtle rotation dependencies.
- **🌌 Pattern Hunter Collections** — Rare and aesthetically pleasing configurations.

Each family contains a description of its overall "personality" — the kinds of scrambles that tend to produce it, and the recognition cues that help you spot it quickly.

## 🧭 How to Navigate This Atlas

If you're brand new, start with the **Beginner Learning Path**. It guides you through eight core cases that cover the majority of friendly scrambles.

If you've been solving for a while, dip into the **Intermediate Families** and use the difficulty tags to find cases that genuinely stretch you without overwhelming you.

If you're an advanced solver hunting for elegance, the **Pattern Hunter Collections** are your playground. These cases are curated for beauty as much as utility.

Every case page includes:

- A plain-language description of the starting state.
- A recognition cue written as a memorable phrase.
- At least one solution path, often two.
- Notes on which rotations preserve or alter the case.
- Cross-links to neighbouring cases that appear in similar scrambles.
